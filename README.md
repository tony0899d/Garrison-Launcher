# Garrison RP — Launcher

Launcher oficial do **Garrison RP** (RedM). Abre o jogo já conectado no servidor e
deixa o RedM configurado para rodar melhor.

### O que ele faz

- **Entrar com um clique** — abre o RedM direto no servidor (`cfx.re/join/4gg7aav`).
- **Ajustes do jogo** — libera mais props, luzes e portas no RedM. Dá para ligar e
  desligar quando quiser: o launcher guarda o original e devolve igual.
- **Limpar cache** — resolve travamento e carregamento infinito sem precisar caçar
  pasta no Windows.
- **Status do servidor** — mostra se está online e quantos jogadores estão dentro.
- **Atualização automática** — avisa e instala a versão nova sozinho.
